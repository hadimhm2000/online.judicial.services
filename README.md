# 🤖 بات اتوماسیون خدمات قضایی آنلاین

ربات تلگرام برای اتوماسیون ثبت لوایح و اسناد در سامانه قضایی ثنا (sakha2.adliran.ir) با استفاده از Playwright

## 📋 امکانات

### ✅ قابلیت‌های فعلی:
- 📝 **ثبت لایحه**: ثبت خودکار لایحه در سامانه ثنا
- ⚖️ **اعلام وکالت**: ثبت اعلام وکالت با پشتیبانی از چند وکیل
- 📄 **اظهارنامه**: ثبت اظهارنامه در سامانه
- 📲 **جستجوی شماره همراه**: استعلام اطلاعات اشخاص از روی شماره تلفن
- 🔍 **جستجوی کد ملی**: استعلام اطلاعات شخص حقیقی
- 💰 **محاسبه تمبر**: محاسبه خودکار هزینه تمبر
- ✍️ **امضای لایحه**: امضای دیجیتال لوایح
- 📊 **گزارش‌گیری**: ذخیره اطلاعات در Google Sheets

### 🆕 اصلاحات اخیر (۶ مرداد ۱۴۰۵):

#### ۱. تشخیص پیام خطای ثنا در جستجوی شماره همراه

- ✅ نمایش متن کامل پیام به کاربر
- ✅ توقف خودکار فرآیند در صورت خطا

#### ۲. بهبود فرآیند اعلام وکالت

- ✅ کلیک خودکار دکمه استعلام ثنا
- ✅ کلیک خودکار دکمه "ثبت موقت" بعد از استعلام موفق
- ✅ پشتیبانی از افزودن چندین وکیل به صورت متوالی

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها:
- Python 3.8 یا بالاتر
- حساب کاربری در سامانه ثنا (sakha2.adliran.ir)
- توکن بات تلگرام (از [@BotFather](https://t.me/botfather))
- Google Sheets API credentials (اختیاری - برای گزارش‌گیری)

### مراحل نصب:

1️⃣ **کلون کردن پروژه:**
```bash
git clone https://github.com/hadimhm2000/online.judicial.services.git
cd online.judicial.services
```

2️⃣ **ایجاد محیط مجازی:**
```bash
python -m venv venv
source venv/bin/activate  # در لینوکس/مک
# یا
venv\Scripts\activate  # در ویندوز
```

3️⃣ **نصب وابستگی‌ها:**
```bash
pip install -r requirements.txt
playwright install chromium
```

4️⃣ **تنظیمات محیطی:**

فایل `.env` ایجاد کنید:
```env
# توکن بات تلگرام
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# اطلاعات ورود به سامانه ثنا
SANA_USERNAME=09123456789
SANA_PASSWORD=your_password_here

# شناسه کاربری ادمین تلگرام
ADMIN_ID=123456789

# اطلاعات بانکی (برای ارسال به کاربران)
CARD_NUMBER=6037-9977-1234-5678
ACCOUNT_NAME=نام صاحب حساب

# Google Sheets (اختیاری)
GOOGLE_SHEET_ID=your_sheet_id_here
```

5️⃣ **راه‌اندازی:**
```bash
python bot.py
```

## 📖 نحوه استفاده

### 1️⃣ شروع کار با بات:
- بات را در تلگرام استارت کنید: `/start`
- از منوی اصلی گزینه مورد نظر را انتخاب کنید

### 2️⃣ ثبت اعلام وکالت:
```
⚖️ اعلام وکالت → 
   📝 کد ملی وکیل اول →
   ➕ افزودن وکیل دیگر (اختیاری) →
   🔢 شماره قرارداد وکالت →
   💰 مبلغ تمبر →
   📄 متن لایحه →
   📎 پیوست‌ها (اختیاری) →
   ✅ تایید نهایی
```

بات به صورت خودکار:
- هر وکیل را در سامانه ثنا جستجو می‌کند
- استعلام می‌گیرد
- ثبت موقت می‌کند
- به وکیل بعدی می‌رود
- در نهایت متن لایحه را وارد می‌کند

### 3️⃣ جستجوی شماره همراه:
```
📲 جستجوی شماره همراه →
   🔢 وارد کردن شماره موبایل →
   ⏳ منتظر نتیجه استعلام
```

اگر شماره در ثنا ثبت نباشد:
```
⚠️ پیام سامانه:

شماره همراه « 09132732495 » در پایگاه داده ثنا 
بنام هیچ شخص حقیقی یا حقوقی ثبت نشده است .

فرآیند متوقف شد.
```

### 4️⃣ ثبت لایحه:
```
📝 ثبت لایحه →
   🔢 کد رهگیری پرونده →
   📍 استان →
   📝 شماره ردیف فرعی →
   📄 متن لایحه →
   📎 پیوست‌ها →
   ✅ ارسال
```

## 🔧 تنظیمات پیشرفته

### استفاده از پروکسی:
در فایل `browser_helpers.py` می‌توانید تنظیمات پروکسی را اضافه کنید:

```python
browser = await playwright.chromium.launch(
    headless=True,
    proxy={
        "server": "http://proxy.example.com:8080",
        "username": "user",
        "password": "pass"
    }
)
```

### تنظیم timeout ها:
در فایل `config.py`:
```python
DEFAULT_TIMEOUT = 30000  # 30 ثانیه
SEARCH_TIMEOUT = 60000   # 60 ثانیه برای جستجو
```

### لاگینگ:
سطح لاگ را می‌توانید تغییر دهید:
```python
logging.basicConfig(level=logging.DEBUG)  # برای دیباگ دقیق‌تر
```
