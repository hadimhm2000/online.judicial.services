# راهنمای فایل داده شعب قضایی

## مقدمه

این ربات برای انتخاب شعب قضایی از یک ساختار درختی استفاده می‌کند. فایل `units_compact.json` شامل اطلاعات تمامی واحدهای قضایی کشور است.

## ساختار فایل

فایل `units_compact.json` یک آرایه JSON است که هر عنصر آن یک واحد قضایی را نمایش می‌دهد:

```json
{
  "Id": "شناسه یکتا",
  "ParentId": "شناسه والد",
  "ParentUnitId": "شناسه والد (فیلد جایگزین)",
  "UnitName": "نام واحد",
  "Code": "کد واحد (فقط برای واحدهای نهایی)",
  "UnitNo": "شماره واحد",
  "UnitType": "نوع واحد (عددی)",
  "HasChildUnit": true/false,
  "HasSelectUnit": true/false,
  "Depth": "عمق در درخت",
  "Path": "مسیر کامل از ریشه"
}
```

## فیلدهای مهم

### Code (کد واحد)
- **بسیار مهم**: فقط واحدهایی که دارای `Code` غیر خالی هستند قابل انتخاب در فرآیند ثبت لایحه هستند
- واحدهای بدون کد (مثل دادگستری‌های استانی) فقط برای ناوبری در درخت استفاده می‌شوند
- این کد در API ثبت لایحه استفاده خواهد شد

### HasChildUnit
- `true`: واحد دارای زیرمجموعه است (مثل دادگستری استان)
- `false`: واحد نهایی است (مثل شعبه دادگاه)

### HasSelectUnit
- `true`: واحد قابل انتخاب است
- `false`: واحد فقط برای ناوبری است

## سطوح سلسله مراتبی

1. **سطح 0**: قوه قضائیه (ریشه)
2. **سطح 1**: سازمان‌های اصلی و دادگستری‌های استانی (حدود 40 مورد)
   - دیوان عالی کشور
   - دیوان عدالت اداری
   - سازمان قضایی نیروهای مسلح
   - دادگستری استان‌ها (31 استان)
3. **سطح 2**: انواع دادگاه‌ها
   - دادگاه‌های عمومی حقوقی
   - دادگاه‌های عمومی کیفری
   - دادگاه‌های خانواده
   - دادگاه‌های تجدیدنظر
   - دادگاه‌های انقلاب
   - و غیره...
4. **سطح 3+**: شعب دادگاه‌ها (واحدهای نهایی با کد)

## نحوه دریافت فایل کامل

فایل فعلی `units_compact.json` یک نمونه است. برای دریافت فایل کامل:

1. از API سامانه قضایی درخواست دهید
2. یا فایل `all_units.json` را از منبع معتبر دریافت کنید
3. برای کوچک‌تر کردن حجم فایل، اسکریپت `make_compact_units.py` را اجرا کنید:

```bash
python make_compact_units.py
```

این اسکریپت فقط فیلدهای ضروری را نگه می‌دارد و حجم فایل را کاهش می‌دهد.

## تست سیستم

برای تست سیستم با داده نمونه:

```bash
python bot.py
```

در ربات:
1. گزینه "ثبت لایحه" را انتخاب کنید
2. در قسمت انتخاب شعبه، "انتخاب از لیست شعب" را بزنید
3. از درخت ناوبری کنید تا به شعبه مورد نظر برسید
4. فقط شعب با آیکون ✅ قابل انتخاب هستند

## نکات مهم

⚠️ **هشدار**: بدون فایل داده کامل، سیستم فقط با داده‌های نمونه کار می‌کند که شامل تعداد محدودی از شعب است.

✅ **توصیه**: برای استفاده در محیط تولید، حتماً فایل کامل با تمامی 40+ شاخه اصلی و هزاران شعبه را تهیه کنید.

## ساختار بهینه

برای کارایی بهتر:
- فایل `units_compact.json` باید در ریشه پروژه قرار گیرد
- حجم فایل بهتر است زیر 5MB باشد
- برای فایل‌های بزرگ‌تر، می‌توانید از فشرده‌سازی استفاده کنید

## پشتیبانی

در صورت نیاز به راهنمایی بیشتر یا دریافت فایل کامل، با تیم فنی تماس بگیرید.
