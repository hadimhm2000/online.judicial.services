# 🏛 سیستم مدیریت شعب قضایی

## معرفی

این ماژول امکان **جستجو و انتخاب شعب قضایی به صورت درختی** را فراهم می‌کند. کاربران می‌توانند از طریق یک رابط کاربری تعاملی، در میان هزاران شعبه و واحد قضایی جستجو کرده و شعبه مورد نظر خود را انتخاب کنند.

---

## ویژگی‌ها

✅ **نمایش درختی (Hierarchical):** سلسله‌مراتب کامل از قوه قضائیه تا شعبه نهایی  
✅ **صفحه‌بندی (Pagination):** نمایش ۸ آیتم در هر صفحه  
✅ **دکمه‌های ناوبری:** بازگشت، صفحه قبل/بعد، ریشه  
✅ **Inline Keyboard:** استفاده از دکمه‌های inline تلگرام  
✅ **بهینه‌سازی callback_data:** استفاده از index به جای ID کامل  
✅ **نمایش اطلاعات کامل:** نمایش تمام جزئیات واحد انتخابی  
✅ **یکپارچگی با سیستم لایحه:** امکان انتخاب شعبه در فرآیند ثبت لایحه  

---

## نحوه استفاده

### ۱. دستور مستقل `/branches`

کاربر می‌تواند در هر زمان از دستور `/branches` استفاده کند:

```
/branches
```

ربات لیست شعب را به صورت درختی نمایش می‌دهد.

### ۲. در فرآیند ثبت لایحه

هنگام انتخاب "شعبه رسیدگی کننده و شماره بایگانی"، کاربر دو گزینه دارد:
- **📝 وارد کردن نام شعبه:** نام را تایپ می‌کند
- **🔍 انتخاب از لیست شعب:** از منوی درختی انتخاب می‌کند

## ساختار داده

### فایل ورودی

یکی از این فایل‌ها باید در ریشه پروژه موجود باشد:
- `units_compact.json` (توصیه می‌شود)
- `all_units.json`
- `sample_units.json` (برای تست)

### فرمت JSON

```json
[
  {
    "Id": "BRANCH101",
    "ParentId": "COURT001",
    "ParentUnitId": "COURT001",
    "UnitName": "شعبه ۱۰۱",
    "Code": "TEH-CRT-101",
    "UnitNo": "101",
    "UnitType": 40,
    "HasChildUnit": false,
    "HasSelectUnit": true,
    "Depth": 3,
    "Path": "قوه قضائیه / ... / شعبه ۱۰۱"
  }
]
```

### فیلدهای مهم

| فیلد | توضیح | نمونه |
|------|-------|-------|
| `Id` | شناسه یکتا | `"BRANCH101"` |
| `ParentId` | شناسه والد | `"COURT001"` |
| `UnitName` | نام واحد | `"شعبه ۱۰۱"` |
| `Code` | کد واحد | `"TEH-CRT-101"` |
| `UnitNo` | شماره واحد | `"101"` |
| `UnitType` | نوع واحد | `40` |
| `HasChildUnit` | دارای فرزند؟ | `true/false` |
| `HasSelectUnit` | قابل انتخاب؟ | `true/false` |
| `Depth` | عمق در درخت | `0, 1, 2, 3, ...` |
| `Path` | مسیر کامل | `"قوه قضائیه / ..."` |

## ساختار داخلی

### دیکشنری‌های کمکی

```python
ID_TO_NODE = {}           # نقشه Id به Node
CHILDREN_BY_PARENT = {}   # نقشه ParentId به لیست فرزندان
INDEX_TO_ID = {}          # نقشه Index عددی به Id
ID_TO_INDEX = {}          # نقشه Id به Index عددی
ROOT_NODES = []           # لیست نودهای ریشه
```

### یافتن ریشه

ریشه به یکی از روش‌های زیر تشخیص داده می‌شود:
1. `Depth == 0`
2. بدون `ParentId` یا `ParentUnitId`
3. والد در دیتا موجود نیست

## فرمت Callback Data

برای کوتاه کردن callback_data (محدودیت تلگرام ۶۴ بایت)، از index عددی استفاده می‌شود:

```
br:open:123:0    → باز کردن فرزندان نود با index=123، صفحه 0
br:page:123:2    → تغییر به صفحه 2 در نود با index=123
br:back:456:0    → بازگشت به نود با index=456
br:sel:789       → انتخاب نود با index=789
br:root:0        → بازگشت به ریشه
```

## کیبورد Inline

### ساختار

```
┌─────────────────────────────────┐
│ 📁 دادگستری استان تهران         │
│ 📁 دادگستری استان اصفهان        │
│ 📄 شعبه ۱۰۱ (101)               │
│ 📄 شعبه ۱۰۲ (102)               │
├─────────────────────────────────┤
│  ◀️ قبلی  │  بعدی ▶️            │
├─────────────────────────────────┤
│  🔙 بازگشت  │  🏠 ریشه          │
└─────────────────────────────────┘
```

### آیکون‌ها

- 📁 → واحدی که فرزند دارد
- 📄 → واحد نهایی (بدون فرزند)

## API Functions

### `load_units_data()`
بارگذاری و پردازش داده‌های شعب از فایل JSON

**Returns:** `True` در صورت موفقیت، `False` در صورت خطا

### `get_children(parent_id: str) -> List[dict]`
دریافت لیست فرزندان یک نود

**Args:**
- `parent_id`: شناسه نود والد

**Returns:** لیست نودهای فرزند

### `create_branches_keyboard(...)`
ساخت کیبورد inline برای نمایش شعب

**Args:**
- `nodes`: لیست نودها برای نمایش
- `page`: شماره صفحه (از 0)
- `parent_id`: شناسه والد (برای دکمه بازگشت)
- `page_size`: تعداد آیتم در هر صفحه (پیش‌فرض: ۸)

**Returns:** `InlineKeyboardMarkup`

### `format_unit_info(node: dict) -> str`
فرمت‌دهی اطلاعات یک واحد برای نمایش

**Args:**
- `node`: دیکشنری اطلاعات نود

**Returns:** متن فرمت شده

## Handlers

### `cmd_branches(message, state)`
هندلر دستور `/branches`

نمایش ریشه درخت شعب

### `process_branch_callback(callback, state)`
هندلر callback های مربوط به شعب

پردازش action های:
- `open`: باز کردن فرزندان
- `page`: تغییر صفحه
- `back`: بازگشت به والد
- `sel`: انتخاب واحد نهایی
- `root`: بازگشت به ریشه

## یکپارچگی با سیستم لایحه

وقتی کاربر در state `Form.lavayeh_branch_name` است و شعبه را از لیست انتخاب می‌کند:

1. نام شعبه در state ذخیره می‌شود
2. پیام تأیید نمایش داده می‌شود
3. کاربر به مرحله انتخاب استان هدایت می‌شود

```python
# در callback handler
if current_state == Form.lavayeh_branch_name:
    branch_name = node.get("UnitName", "")
    await state.update_data(lavayeh_branch_name=branch_name)
    # ادامه به انتخاب استان
    await state.set_state(Form.lavayeh_province)
```

## عیب‌یابی

### فایل داده پیدا نمی‌شود
```
⚠️ داده‌های شعب در دسترس نیست.
```

**راه‌حل:** یکی از فایل‌های زیر را در ریشه پروژه قرار دهید:
- `units_compact.json`
- `all_units.json`
- `sample_units.json`

### خطای "واحد مورد نظر یافت نشد"
```
❌ خطا: واحد مورد نظر یافت نشد.
```

**راه‌حل:** 
- فایل داده را دوباره بارگذاری کنید
- بررسی کنید که Id ها یکتا هستند

### کیبورد خالی است
**دلیل:** نود فرزند ندارد

**راه‌حل:** این رفتار طبیعی است. برای نودهای برگ (leaf)، اطلاعات کامل نمایش داده می‌شود.
