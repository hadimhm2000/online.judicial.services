# توضیحات به‌روزرسانی بخش لایحه

## تغییرات اعمال شده

### ۱. اضافه شدن گزینه‌های جدید برای ثبت شماره پرونده

در بخش ثبت لایحه، پس از انتخاب عنوان لایحه، دو گزینه برای کاربر نمایش داده می‌شود:

1. **شماره پرونده و ردیف فرعی** (مسیر قبلی که همچنان کار می‌کند)
2. **شعبه رسیدگی کننده و شماره بایگانی** (مسیر جدید)

### ۲. مسیر اول: شماره پرونده و ردیف فرعی
اگر کاربر گزینه **"1️⃣ شماره پرونده و ردیف فرعی"** را انتخاب کند:
- از او شماره پرونده درخواست می‌شود
- شماره پرونده با قوانین موجود اعتبارسنجی می‌شود:
  - پرونده‌های ۱۴۰۰ تا ۱۴۰۷: باید ۱۸ رقمی باشند
  - پرونده‌های ۱۳۹۹ و قبل‌تر: باید ۱۶ رقمی باشند
- سپس استان را انتخاب می‌کند
- و در نهایت ردیف فرعی (عددی بین ۱ تا ۳۰) را وارد می‌کند

### ۳. مسیر دوم: شعبه رسیدگی کننده و شماره بایگانی
اگر کاربر گزینه **"2️⃣ شعبه رسیدگی کننده و شماره بایگانی"** را انتخاب کند:

#### مرحله ۱: شماره بایگانی
از کاربر شماره بایگانی درخواست می‌شود با قوانین زیر:
- اگر دو رقم اول شماره **۰۰ تا ۰۷** باشد → باید **۷ رقمی** باشد
- اگر دو رقم اول شماره **۹۳ تا ۹۹** باشد → باید **۶ رقمی** باشد
- در غیر این صورت خطا داده می‌شود

#### مرحله ۲: نام شعبه
پس از تایید شماره بایگانی، کاربر می‌تواند نام شعبه را به دو روش وارد کند:

#### روش ۱: وارد کردن دستی
کاربر نام شعبه را به صورت دستی تایپ می‌کند (مثلاً "شعبه ۱۰۱ دادگاه عمومی حقوقی تهران")

#### روش ۲: انتخاب از لیست (قابلیت جدید)
کاربر می‌تواند از طریق منوی درختی، شعبه مورد نظر خود را انتخاب کند:
- نمایش سلسله‌مراتبی واحدها و شعب
- صفحه‌بندی خودکار (۸ آیتم در هر صفحه)
- امکان بازگشت به مراحل قبل
- جستجوی آسان در درخت سازمانی

**نکته:** برای استفاده از این قابلیت، فایل `units_compact.json` یا `all_units.json` باید در ریشه پروژه موجود باشد.

#### مرحله ۳: استان
کاربر استان مربوط به پرونده را انتخاب می‌کند.

**توجه:** در این مسیر، نیازی به وارد کردن ردیف فرعی نیست و مستقیماً به بخش اشخاص یا مراحل بعدی منتقل می‌شود.

### ۴. نمایش در پیش‌نمایش
در بخش پیش‌نمایش لایحه:
- اگر کاربر از **مسیر اول** استفاده کرده باشد، اطلاعات شماره پرونده، استان و ردیف فرعی نمایش داده می‌شود
- اگر کاربر از **مسیر دوم** استفاده کرده باشد، اطلاعات شماره بایگانی، نام شعبه و استان نمایش داده می‌شود

## فایل‌های تغییر یافته

### ۱. `states.py`
State‌های جدید اضافه شده:
- `lavayeh_tracking_method`: برای انتخاب روش (شماره پرونده یا شماره بایگانی)
- `lavayeh_archive_number`: برای دریافت شماره بایگانی
- `lavayeh_branch_name`: برای دریافت نام شعبه

### ۲. `keyboards.py`
کیبورد جدید اضافه شده:
- `lavayeh_tracking_method_kb`: کیبورد انتخاب روش با دو گزینه و دکمه بازگشت

### ۳. `lavayeh_handlers.py`
تغییرات شامل:
- اضافه شدن تابع `validate_archive_number()` برای اعتبارسنجی شماره بایگانی
- اضافه شدن هندلر `lavayeh_get_tracking_method()` برای انتخاب روش
- اضافه شدن هندلر `lavayeh_get_archive_number()` برای دریافت شماره بایگانی
- اضافه شدن هندلر `lavayeh_get_branch_name()` برای دریافت نام شعبه
- به‌روزرسانی هندلر `lavayeh_get_title()` برای نمایش کیبورد انتخاب روش
- به‌روزرسانی هندلر `lavayeh_get_province()` برای مدیریت هر دو مسیر
- به‌روزرسانی توابع `build_preview()` و `_build_ealam_preview()` برای نمایش صحیح اطلاعات

## نحوه تست

۱. ربات را اجرا کنید
۲. دستور `/start` یا "📝 ثبت لایحه" را بزنید
۳. یک عنوان لایحه انتخاب کنید
۴. در صفحه انتخاب روش، یکی از دو گزینه را امتحان کنید:

### تست مسیر اول:
- "1️⃣ شماره پرونده و ردیف فرعی" را انتخاب کنید
- یک شماره پرونده معتبر وارد کنید (مثلاً `14001234567890123۴` برای ۱۸ رقمی)
- استان را انتخاب کنید
- ردیف فرعی (مثلاً `1`) را وارد کنید

### تست مسیر دوم:
- "2️⃣ شعبه رسیدگی کننده و شماره بایگانی" را انتخاب کنید
- یک شماره بایگانی معتبر وارد کنید:
  - برای ۷ رقمی: `0012345` (شروع با ۰۰ تا ۰۷)
  - برای ۶ رقمی: `931234` (شروع با ۹۳ تا ۹۹)
- نام شعبه را وارد کنید (مثلاً "شعبه ۱۰۱ دادگاه عمومی تهران")
- استان را انتخاب کنید

## نکات مهم

۱. **حفظ سازگاری با کد قبلی**: تمام مسیرهای قبلی کماکان کار می‌کنند
۲. **اعتبارسنجی دقیق**: هر دو روش validation کامل دارند
۳. **پیام‌های راهنما**: پیام‌های کمکی برای کاربر نمایش داده می‌شود
۴. **دکمه بازگشت**: در تمام مراحل امکان بازگشت به مرحله قبل وجود دارد
۵. **ذخیره روش انتخابی**: روش انتخاب شده در state ذخیره می‌شود و در پیش‌نمایش استفاده می‌شود

## متغیرهای State جدید

در `data` ذخیره می‌شود:
- `tracking_method`: مقدار `"case_number"` یا `"archive_number"`
- `lavayeh_archive_number`: شماره بایگانی (در صورت استفاده از مسیر دوم)
- `lavayeh_branch_name`: نام شعبه (در صورت استفاده از مسیر دوم)
- `lavayeh_tracking_code`: شماره پرونده (در صورت استفاده از مسیر اول)
- `lavayeh_row_number`: ردیف فرعی (در صورت استفاده از مسیر اول)
